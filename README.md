# 院内研修・勉強会スケジュール（長崎北徳洲会病院）

委員会・本部・各部署が実施する講習会・勉強会・研修会（年間約40件）を、
全職員が電子カルテ系ネットワーク上で確認できるイントラネットアプリです。
予定は**主催の担当者が自分で登録**し、管理者（教育委員会 等）が承認すると掲載されます。

既存の院内アプリ（レセプト集計・空きベッド情報・問い合わせ受付・ジョブ管理）と同じ構成です。
フォルダ1つを Apache の htdocs に置くだけで動き、インターネット接続や外部サービスは不要です。

| フォルダ | アプリ | サーバー配置先 | URL例 |
|---|---|---|---|
| `education/` | 研修・勉強会スケジュール（閲覧・登録はログイン不要／承認は管理者） | `C:\Apache24\htdocs\education` | `http://10.20.103.125/education/` |

## 画面

| 画面 | 内容 | 使う人 |
|---|---|---|
| `index.php` 予定一覧 | 今後の予定を月ごとに表示。期間・月・種別・主催・対象職種・キーワードで絞り込み。オンラインは「視聴受付中」「締切間近」を表示 | 全職員 |
| `calendar.php` カレンダー | 月間カレンダー。オンライン視聴は視聴期間中の毎日に帯で表示（開始日「配信開始」・終了日「締切」） | 全職員 |
| `view.php` 詳細 | 日時（視聴期間）・会場・対象・内容・担当者連絡先・変更履歴 | 全職員 |
| `new.php` 予定を登録 | 登録申請（ログイン不要）。**会場開催／オンライン視聴（期間指定）**を選べる。**過去の研修から複製**して日付だけ入れ直せる | 担当者（誰でも） |
| `edit.php` 変更・中止 | 登録時に決めた**編集用パスワード**で変更・中止 | 担当者 |
| `admin.php` 承認・管理 | 初回設定／ログイン、承認・差戻し・変更確認・中止取消・削除・編集用パスワード再設定・年度CSV出力 | 管理者 |
| `masters.php` 選択肢の管理 | 主催（委員会・本部・部署）・会場・配信方法（CHATIS・GAKKEN など）・対象職種・種別の追加・名前変更・並び替え・使用停止 | 管理者 |
| `accounts.php` 管理者アカウント | 管理者の追加・氏名変更・パスワード再設定・無効化、自分のパスワード変更 | 管理者 |

## 「全職員が担当者になり得る」ための仕組み

- **登録にログインは不要**。氏名・所属・内線を入力して申請します（職員マスタの登録・異動対応は不要）
- 申請時に本人が**編集用パスワード**（4文字以上）を決め、後から自分で変更・中止できます
- **管理者はログインID＋パスワード**（画面で追加・変更）。承認者名はログインした管理者の氏名で記録されます。
  承認・差戻し・削除ができ、編集用パスワードを忘れた担当者の予定も代わりに直せます
- 承認後に担当者が変更した場合、**掲載は止めずに「変更あり」と表示**し、管理画面に変更点（旧→新）が出ます
- 中止した研修は一覧・カレンダーに**取り消し線**で残ります
- すべての操作（登録・編集・承認・中止・削除・ログイン失敗）を `edu_logs` に記録します
- パスワード誤りが続く端末（IP）は一定時間ロックします

## 設置手順

1. `education` フォルダごとサーバへコピーする（例: `C:\Apache24\htdocs\education`）
2. `education/config.local.php.example` を `config.local.php` にコピーし、
   `mysql` を記入する（レセプトアプリと同じ MySQL・DBでよい。`receipt/config/config.php` と同じ値）
3. ブラウザで `admin.php`（画面上部の「管理」）を開き、**初回設定**で最初の管理者（ログインID・氏名・パスワード）を作成する
   - 初回設定は管理者が1人もいない間だけ表示されます。設置したらすぐに作成してください
   - 2人目以降は「管理者アカウント」画面から追加します
4. 「選択肢の管理」で、主催（委員会・本部・部署）・会場・対象職種・種別を病院の実態に合わせる
   - 最初は `config.php`（`config.local.php` に書いた場合はその値）が初期値として登録されます。以後は画面での変更が正です
5. ブラウザで `check.php` を開き、全項目OKを確認する
   - テーブル（`edu_events` / `edu_logs` / `edu_masters` / `edu_admins`）は初回アクセス時に自動作成・自動更新（セットアップ操作は不要）

### 以前の版から更新する場合

- フォルダを上書きコピーするだけで、開催形式の列などは自動で追加されます（登録済みの予定は「会場で開催」扱い）
- `config.local.php` の `admin_password_hash` は使わなくなりました（残っていても無視されます）。
  `admin.php` を開くと初回設定が表示されるので、管理者を作成してください
- `config.local.php` に書いていた委員会などの選択肢は、初回に自動で取り込まれます

操作説明・試験運用用に、デモデータ（今年度45件・うちオンライン視聴5件）を入れることもできます:
`php tools/demo_data.php`（削除して入れ直す場合は `--clear`。担当者名「デモ」の予定が対象）

## 必要環境

- PHP 8.0 以上（拡張: `pdo_mysql`, `mbstring`）
- MySQL 5.7 以上 / MariaDB 10.3 以上
- Apache 2.4
- 閲覧端末: Microsoft Edge / Chrome（JavaScript・外部ライブラリ不使用）

## データの保存場所とバックアップ

- 予定: `edu_events`、操作履歴: `edu_logs`、選択肢: `edu_masters`、管理者: `edu_admins`（いずれも MySQL）
- バックアップは `mysqldump receipt_db edu_events edu_logs edu_masters edu_admins`（添付ファイルは扱いません）

## セキュリティ上の注意

- 院内イントラネット専用です。インターネットには公開しないでください。
- 全フォームに CSRF 対策、出力は全てエスケープ、SQL はプリペアドステートメント
- パスワード（管理者・編集用）はハッシュ（`password_hash`）でのみ保存します
- 管理者のログイン失敗が続く端末（IP）は一定時間ロックします。最後の有効な管理者・自分自身は無効化できません
